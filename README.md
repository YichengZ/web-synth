# 🧪 AI Synth Lab (Web Audio Experiments)

Welcome to my digital audio laboratory. This repository hosts a collection of browser-based synthesizers, effects, and DSP tools.

All four instruments request a 96kHz Web Audio context and export stereo 24-bit WAV recordings at the actual sample rate accepted by the browser.

**What makes this special?**
Every line of DSP (Digital Signal Processing) code and UI logic in this project was generated by AI, guided by my prompt engineering and sound design expertise. It's an exploration of human-AI collaboration in audio tool development.

## 📦 Modules

### 1. CONVERGENCE (Generative Fusion DSP)
- **Engine:** Shared TITAN, Kawaii, and PRISM stem architecture
- **Concept:** Related low, mid, and high-frequency voices generated from one scene seed.
- **Features:**
  - BURST and evolving DRIFT playback
  - Seed-advancing scenes with 1-4 irregular sub-triggers and randomized stem emphasis
  - Bass drop, rise, pulse, bounce, and glide gestures plus varied stab, chord, ribbon, swell, and cascade voices
  - Pitch-related harmonic voices instead of noise-based source layers
  - Seed-randomized per-stem modulated delay, granular delay, and all-pass dispersion
  - Per-stem oversampled color drive followed by real-time STFT tonal denoising
  - L3-style and RC Inflator presets plus a default BRUTAL serial bus
  - BRUTAL: up to +18dB drive, five-band limiting, RC color, transient shaping, and a -1dB clip ceiling
  - Shared 96kHz, 24-bit stereo recorder

The mastering presets are original Web Audio implementations inspired by public product behavior; they do not reproduce proprietary Waves or Musik Hack DSP code.

### 2. PRISM (Organic Light Physics Synth)
- **Engine:** Web Audio API (96kHz ready)
- **Concept:** Drifting oscillators simulating light refraction physics.
- **Features:**
  - 10+ Organic Physics Engines (Lumen, Shard, Halo, etc.)
  - Real-time Canvas Visualizer
  - 24-bit stereo WAV recording

### 3. TITAN SUB (Cinematic Deep Bass)
- **Engine:** Custom Quad-Source Web Audio DSP
- **Concept:** Deep sub-bass engine optimized for low-frequency playback.
- **Features:**
  - Multi-layer Morphing (Drop, Impact, Rumble)
  - Stereo Quadrature Shapers & Phase-safe Width
  - Analog-style Saturation & Inflator
  - Editable pitch/amplitude envelopes with touch support

### 4. KAWAII SYNTH (Anime SFX Engine)
- **Engine:** Web Audio API + React
- **Concept:** A cute and colorful synthesizer playground for anime-style sound effects.
- **Features:**
  - **Presets:** Physics (Bubble, Boing), Emotes (Happy, Angry), and Magic textures.
  - **Controls:** Interactive Oscilloscope, preset locks, and Randomizer.
  - **FX:** Tape Delay, Wobble, and Sparkle Reverb. 

## 🛠️ Tech Stack
- **Core:** JavaScript + Web Audio API + AudioWorklet
- **UI:** React + Tailwind CSS, bundled locally with Vite
- **Generation:** AI Model (Claude/Gemini/GPT)

## Development

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite. Production assets are generated in `docs/`:

```bash
npm run build
npm test
```

The test suite checks desktop/mobile layout, console errors, accessibility labels, and WAV downloads.

## Offline Testing

Copy the complete `docs/` directory to the offline computer. It contains all application code and styles; no CDN or Google Fonts connection is required.

- macOS/Linux: run `sh START_OFFLINE.command`
- Windows: double-click `START_OFFLINE.bat`
- Open `http://localhost:8080/`

Python 3 must already be installed on the offline computer. Do not open `index.html` directly because browsers restrict module-based audio applications on `file://` URLs.

Keyboard controls: `Space` triggers sound, `R` toggles recording, and `Escape` stops the PRISM sequencer or current TITAN voice. Settings are retained in the browser on each computer.
